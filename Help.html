Wi-Fi Emulator Accept

Wi-Fi Emulator Accept is a pure .NET program for Windows only. When Wi-Fi reconnects, it clicks Allow or Accept on the emulator prompt.

Two Windows packages are published. One uses the .NET 8 Windows Desktop Runtime. The other uses the .NET 10 Windows Desktop Runtime. The window title shows the runtime for this copy, for example Wi-Fi Emulator Accept (.NET 10). The line under the introduction repeats it: pure .NET program for Windows only, and the runtime this copy uses.

Status

The bold status shows the live state:

  • Wi-Fi: connected to the network name, or Wi-Fi: disconnected.
  • Watching is on means a reconnect starts a scan. Watching is paused means a reconnect does not.
  • Starts at sign-in means Windows launches the program in the tray. Starts only when opened means it runs only after you open it.
  • Extra window titles are listed when the title box is filled in.
  • Pure .NET program for Windows only names the Windows Desktop Runtime this copy uses, .NET 8 or .NET 10.

The watching sentence is written to the log and shown in the tray tooltip. The pure .NET line is shown in the window title, under the introduction, and in the bold status.

What it clicks

It clicks a button named Allow, Allow access, or Accept. It also clicks 允许, 允许访问, 接受, and 同意.

The window must belong to one of these Windows programs, or its title must name one: QEMU, BlueStacks, LDPlayer, Nox, MEmu, MuMu, or Google Play Games.

Windows consent, credential, and SmartScreen windows are left as they are. Cancel and Don't allow are left as they are.

Extra window titles

Use the title box for a window the names above do not cover. Separate entries with commas or semicolons. Each entry needs at least 3 characters, and it must appear as its own words in the window title.

Example: BlueStacks, LDPlayer, Nox

Leave the box empty when the built-in names are enough.

After Wi-Fi reconnects

A reconnect is a change from disconnected to connected. The first 8 seconds after startup are ignored, and another reconnect within 8 seconds does not start a second watch.

The watch waits 2 seconds, then looks for the prompt for about 40 seconds. It checks about every 4 seconds and stops after 3 clicks. Scan now looks once immediately.

Window and tray

Closing the window leaves the program in the tray. Right-click the Wi-Fi icon and choose Exit to quit. Show opens the window. Help or the F1 key opens this file.

Open log folder opens the folder that holds log.txt and settings.json.

Files

  • Program: %LOCALAPPDATA%\Programs\WifiEmulatorAccept
  • Settings and log: %APPDATA%\WifiEmulatorAccept

Install the package that matches the Windows Desktop Runtime on this PC: .NET 8 or .NET 10. Uninstall from Windows Settings, under Apps. The installed name includes the runtime, for example Wi-Fi Emulator Accept (.NET 10).
